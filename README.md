# AI-Resume-Analyzer-Job-Matching-Platform
The AI Resume Analyzer & Job Matching Platform is an end-to-end, production-ready AI application designed to automate resume screening and job matching using Machine Learning, Natural Language Processing (NLP), and Large Language Models (LLMs). The system analyzes resumes and job descriptions, computes semantic match scores, identifies skill gaps, and provides AI-driven resume feedback to help candidates improve their profiles.
This project demonstrates real-world implementation of Data Science, ML, LLMs, backend development, and cloud deployment, making it suitable for roles such as Machine Learning Engineer, Data Scientist, and AI Engineer.
"Problem Statement" - Manual resume screening is time-consuming and often biased. Recruiters rely on keyword matching, which fails to capture semantic meaning. Candidates also lack clear feedback on why their resumes are rejected.This project solves these problems by:Automating resume analysis , Using semantic similarity instead of keyword matching , Providing intelligent, AI-generated feedback
"Solution"- The platform allows users to: Upload a resume (PDF),Provide a job description , Extract skills, experience, and education using NLP , Compute a resume–job match score , Identify missing or weak skills , Generate personalized resume improvement suggestions using LLMs
"Tools & Technologies Used" - Programming & Backend-Python , FastAPI , Uvicorn , Machine Learning & NLP , spaCy , Scikit-learn
"Sentence Transformers" - TF-IDF,Cosine Similarity ,LLMs & Agentic AI , Large Language Models (LLMs),LangChain
"Data Processing" - PDFPlumber,NumPy, Pandas, Frontend / Dashboard
"Streamlit" - DevOps & Deployment , Docker , AWS EC2, AWS S3 , Version Control
